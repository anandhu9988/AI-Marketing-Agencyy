# Brand kit: First Commit

> The client brand our AI Marketing Agency runs. Every employee reads this file during its install.

## Identity

- **Name:** First Commit
- **Tagline:** Tech tips for people writing their first lines of code.
- **Instagram handle (check availability, in this order):** `@firstcommit.tips` · `@firstcommit.dev` · `@first.commit.daily`
- **Website:** GitHub Pages site in `site/` (link added after publishing)
- **Run by:** three Information Technology students at Riga Nordic University

**Instagram bio (150 characters max):**
> Tech tips for beginners 💻 Git, Python, VS Code & how the web works, one small tip at a time. By 3 IT students in Riga 🇱🇻

## Audience

- First- and second-year IT and computer science students
- Self-taught beginners learning Python or web development
- People switching careers into tech who feel lost in jargon

**What they need:** short, correct, practical tips they can try in five minutes, explained without jargon.

## Voice

- **Friendly peer, not a lecturer.** We are students too: "we learned this the hard way".
- **Plain words first, the technical term second.** "A branch is a copy you can experiment on (a *branch*)."
- **Accurate or silent.** Every command and shortcut is tested before posting. No made-up statistics.
- **Short.** One idea per post. Captions under 120 words.
- **Never:** hype ("10x your coding!"), fear ("you're falling behind"), or putting beginners down.

## Content pillars

| Pillar | Example topics | Format |
|---|---|---|
| Git & GitHub | init/add/commit, branches, undoing mistakes | Carousel |
| Python basics | list comprehensions, f-strings, virtual environments | Before/after code image |
| Tools & shortcuts | VS Code shortcuts, terminal basics | Single image or Reel |
| How things work | what happens when you type a URL, what an API is | Diagram carousel |
| Student life in tech | study routines, first internship tips | Photo + caption |

**Cadence:** 4 posts a week (Mon, Tue, Thu, Sat) + Stories on post days.

## Visual style

Matches our presentation design: warm ivory `#F2EEE5`, carbon black `#191919`, signal orange `#E64B2E`, concrete grey `#B8B8B0`.
Bold sans-serif headlines, code in a monospace font, lots of empty space, one orange highlight per image.

## First five posts

1. **Hello, World: who we are**
   Carousel: who runs First Commit, what we post, what to expect.
   *Caption:* "Every developer has a first commit. This is ours. We're three IT students in Riga sharing the tips we wish someone had shown us in our first semester. Follow along: one small, tested tip at a time."

2. **Git in 60 seconds**
   Carousel: `git init` → `git add .` → `git commit -m "first commit"`, one command per slide, with what each one does.
   *Caption:* "Three commands to save your first snapshot. init starts tracking a folder, add chooses what to save, commit saves it with a message. That's it."

3. **5 VS Code shortcuts (Windows)**
   `Ctrl+P` quick-open a file · `Ctrl+Shift+P` command palette · `Alt+↑/↓` move a line · `Ctrl+D` select the next match · ``Ctrl+` `` open the terminal.
   *Caption:* "Save this for your next coding session. Mac users: swap Ctrl for Cmd (the terminal is Ctrl+` on both)."

4. **What happens when you type a URL?**
   Diagram carousel: browser → DNS lookup → server → response → page renders.
   *Caption:* "You do it a hundred times a day. Here's what actually happens in the second after you press Enter."

5. **Python: one line instead of four**
   Before/after image: a `for` loop building a list vs. the list comprehension `squares = [n * n for n in range(10)]`.
   *Caption:* "Same result, one line. Use it when it stays readable. If it doesn't, the loop is fine."
