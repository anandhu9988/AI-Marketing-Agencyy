## 3. Google Search Console

1. Go to https://search.google.com/search-console and sign in with the agency Gmail.
2. **Add property → URL prefix** → `https://anandhu9988.github.io/AI-Marketing-Agencyy/`
3. Verification method **HTML file**: download the file Google gives you (named like `google1234abcd.html`).
4. Put it in the repo root (`C:\Users\vjsud\ai\repo`), then `git add .`, `git commit -m "Search Console verification"`, `git push`. Wait 2 minutes and click **Verify**.
5. **Sitemaps** → submit `sitemap.xml`.
6. **URL inspection** → paste the agency page URL → **Request indexing**.

Indexing takes a few days to a few weeks.
